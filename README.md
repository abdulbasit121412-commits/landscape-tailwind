# NOIR — Modern Fashion Landing Page

A modern and responsive fashion website designed with a bold, premium visual style using Tailwind CSS.

## 📌 About

NOIR is a frontend fashion website project focused on creating a modern and visually engaging shopping experience.

The project features a dark luxury-inspired design, responsive layouts, product collections, featured sections, customer testimonials, and contact-focused call-to-action sections.

## ✨ Features

- Fully responsive fashion website
- Modern dark-themed UI
- Responsive navigation
- Hero section with call-to-action
- Latest collections section
- Product category filters
- Featured/craft section
- Customer testimonials
- Contact section
- Responsive layouts for desktop and mobile
- Modern hover and transition effects
- Image-based product presentation

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- JavaScript
- CSS
- Responsive Web Design

## 📄 Main Sections

- Home
- Latest Collections
- Featured Content
- Customer Testimonials
- Contact

## 🎯 Project Purpose

This project was created as a frontend practice and showcase project to improve skills in:

- Tailwind CSS
- Responsive web design
- Modern UI development
- Layout and component structuring
- Visual hierarchy
- Frontend implementation
